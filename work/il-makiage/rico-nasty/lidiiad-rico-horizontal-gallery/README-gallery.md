# Teen Vogue horizontal gallery

The separate Rico Nasty case page contains 3 Teen Vogue pictures as a horizontal scroll-snap gallery. Use swipe/touch, trackpad horizontal scroll, arrow buttons, or keyboard arrow keys when focused. Images currently load directly from Teen Vogue's CDN (they are not downloaded into this ZIP), so they require an internet connection and the publisher's server to allow hotlinking. For permanent hosting, obtain permission to republish and host authorized copies locally. Only `work/il-makiage/rico-nasty/index.html` needs replacement in GitHub.
